# Contributing to Awesome CITY THE ANIMATION

Thank you for helping grow **Awesome CITY THE ANIMATION** into the most accurate, comprehensive community hub for *CITY* and *CITY THE ANIMATION*!

## Curation Standards

Every pull request should follow these principles:

1. **Verified & Accurate** - Visit every URL yourself before submitting. Confirm the page matches the title and description with no soft-404s or wrong IDs.
2. **Work-Specific Links** - Prefer dedicated *CITY* / *CITY THE ANIMATION* pages over generic homepages or broad channels.
3. **Legal & Publicly Accessible** - Never add piracy links, unauthorized episode/OST re-uploads, or private mirrors.
4. **Timeless Descriptions** - Briefly explain *why* each resource is valuable. Avoid volatile claims like live ratings, view counts, or temporary stock availability.
5. **Markdown Link Hygiene** - Percent-encode parentheses inside URLs (`%28` / `%29`) so Markdown parsers and automated link checkers never truncate them.
6. **Bilingual Parity** - Update both [`README.md`](README.md) (English) and [`README.zh.md`](README.zh.md) (Simplified Chinese) in the same pull request.

## Pull Request Checklist

- [ ] Entry is placed in the right section and follows existing formatting (`- [Title](URL) - Concise description.`).
- [ ] Link has been verified live and uses HTTPS whenever available.
- [ ] No duplicate entries exist elsewhere in the list.
- [ ] Both `README.md` and `README.zh.md` are updated together.
- [ ] Reviewed the general [awesome list guidelines](https://github.com/sindresorhus/awesome/blob/main/contributing.md).
